Welcome 👋

This app adds nine ready-made Tableau Pulse metrics to your site, built on data you already have (how your own Tableau site is being used). No spreadsheets, no setup, no waiting.

  • Nine metrics across adoption, performance, and reliability
  • Nothing is created until you review a plan and click Create
  • A one-click Remove button if you ever want to undo it
🔒
Your sign-in details never leave this computer. This app is running locally. It talks straight to your Tableau site and nowhere else.

Takes about 5 minutes. You'll need a Tableau Personal Access Token. Don't have one? The next screen shows you exactly where to create it.

Connect to your Tableau site

Fill in these four things. Not sure where to find one? Click Where do I find this? under any field.

The start of the address you see when you're signed in to Tableau.

Look at your browser's address bar in Tableau. Copy the part that ends in .online.tableau.com. Example: from https://10ax.online.tableau.com/#/site/acme/home you'd copy https://10ax.online.tableau.com.

The short name of your specific site. Leave blank only if your company has a single default site.

In that same web address, it's the word right after /site/. In .../#/site/acme/home, the site name is acme.

The name you gave your token in Tableau. Type it exactly — it's case-sensitive, so capital letters, spaces, and punctuation all have to match.

In Tableau, click your profile picture (top right) → My Account Settings → scroll to Personal Access Tokens. Type a name like Pulse Pack, click Create Token, and copy the secret it shows you (you'll paste that below). Tableau only shows the secret once.

The long code Tableau showed you when you created the token. It's kept hidden as you type.

This is the one-time secret from when you clicked Create Token. If you didn't save it, just create a new token (that's fine) and use the fresh secret.
